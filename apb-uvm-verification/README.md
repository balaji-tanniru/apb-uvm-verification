# AMBA APB UVM Verification

Portfolio-grade verification of an APB3 register slave. The repository includes synthesizable RTL, a portable self-checking SystemVerilog regression, full UVM component structure, protocol assertions, functional coverage, waveforms, and Linux CI.

## Architecture

- APB sequence, sequencer, driver, monitor, scoreboard, coverage subscriber, environment, and test
- Register-array reference model with automated read-data checking
- SVA for setup-to-access timing, stable access controls, and PENABLE/PSEL legality
- Directed valid/error cases and deterministic random traffic

## Run

```bash
sudo apt-get install -y iverilog gtkwave
make test
make wave
```

For actual UVM on Questa Starter Edition:

```bash
make uvm
```
